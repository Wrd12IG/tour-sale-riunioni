# Tour virtuale Sale Riunioni · Brianza Serramenti

Tour 360°, modello 3D e pianta di due sale riunioni collegate dalla porta scorrevole in vetro.

- `index.html` – pagina del tour (pannellum + three.js da CDN)
- `a*.jpg` / `b*.jpg` – panorami 360° Sala 1 / Sala 2
- `ta*.jpg` / `tb*.jpg` – miniature
- `f_*_a.jpg` / `f_*_b.jpg` – texture fotografiche
- `vetrata.mp4` – video del pop-up della vetrata

Pubblicazione: GitHub Pages dal branch `main`, cartella root.
